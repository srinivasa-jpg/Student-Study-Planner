# Student Study Planner

A local-first study planning and focus dashboard.

## Features
- Daily and weekly study planning
- Subjects and topic tasks
- Priority and planned study time
- Completion tracking
- Subject progress
- 7-day study activity chart
- Pomodoro-style 25/50 minute focus timer and break timer
- Study session logging
- Study streaks and daily time totals
- Searchable/filterable plan views
- Responsive mobile design
- Browser localStorage persistence

## Run locally
Open `index.html` or serve the repository with any static web server.
